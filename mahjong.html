마작 손패 분석

손패 사진을 찍으면 노릴 역, 버릴 패, 화료 점수를 알려드려요.

게임 진행
버튼 설명
새 게임 : 손패·울음·바람·연장·마작 룰까지 모두 처음 상태로 돌려요.
연장 : 바람은 그대로 두고 연장을 +1 해요. 손패·울음 구역·도라·깡·리치·상황역(이번 판 정보)은 비워요.
턴넘기기 : 오야가 넘어가요. 자리 바람이 한 칸 앞으로(동→북→서→남→동) 가고, 내 자리가 다시 동이 되면 판 바람이 다음(동→남→서→북)으로 넘어가요. 연장은 0으로, 이번 판 정보는 비워요.
국 번호는 내 자리 바람으로 계산해요 (동=1국, 북=2국, 서=3국, 남=4국).
마작 룰
참가 인원
점수 계산 시 인당 지불 금액에만 반영돼요. 패 구성(만수 1~9 전체 사용 등)은 4인 기준 그대로예요.
2배역(더블 역만) 인정
대사희 · 국사무쌍 13면 대기 · 사암각 단기 · 순정 구련보등(9면 대기)을 2배 역만으로 계산해요. 끄면 모두 보통 역만이에요.

손패 인식
사진을 찍거나 고르면 "인식할 영역"을 지정하는 화면이 떠요. 손패(파랑)와 울음구역(주황)을 패가 크게 보이도록 좁게 맞춰주세요.
현재 손패
패를 탭하면 수정하거나 지울 수 있어요. 13장이면 대기 상태, 14장이면 버릴 패를 계산해요.
울음 구역 (치·퐁·깡)
인식됐지만 아직 안 묶인 패 (탭해서 선택 → 세트로 묶기)
베타 기능 — "어디에 울음패가 있는지"까지는 자동으로 찾지만, "몇 장씩 세트로 묶을지"는 직접 선택해주셔야 해요. 한 번 확정한 세트는 사진을 다시 찍어도 유지되고, 새로 보이는 패만 미분류에 올라와요. 새 판이 시작되면 "울음 전체 비우기"를 눌러주세요. 확정한 세트는 텐파이·대기패·역·부수 계산에 그대로 반영돼요. 이때 손패는 세트 수만큼 줄어든 장수(세트당 3장)로 계산해요.

추천 버릴 패
용어가 어려우면 눌러보세요 (단계 · 유효패 · 대기)
단계(샹텐) : 텐파이(한 장만 더 있으면 완성)까지 남은 단계예요. 숫자가 작을수록 완성에 가까워요.
텐파이 : 한 장만 더 오면 완성되는 상태예요.
대기 : 텐파이일 때 기다리는 패예요. 대기 장수가 많을수록 빨리 완성돼요.
유효패 : 뽑으면 완성에 한 단계 가까워지는 패예요. 많을수록 빨라요.
외톨이 패 : 주변 숫자와 이어지지 않아 완성에 도움이 안 되는 패예요. 먼저 버리기 좋아요.
판수 : 역의 점수 단위예요. 높을수록 점수가 커요.
텐파이 — 대기 패
판수는 지금 설정된 오야·멘젠·리치·바람 기준 참고용이에요. 도라·화료 방식·상황역은 손패가 완성되면 나오는 "화료 옵션"에서 설정해요 (설정해둔 값은 여기 미리보기에도 반영돼요).

인식 모델 상태
이 앱은 내 기기 안에서만 패를 인식해요. 사진은 외부로 전송되지 않고, 인터넷 연결 없이도 동작해요. 같은 폴더에 mahjong-tile-model.onnx 파일이 함께 있어야 해요.
모델을 불러오는 중...
이 도구는 참고용 보조 계산기예요. 울음 구역(치·퐁·깡으로 뺀 패)은 아직 사진으로 자동 인식되지 않아서, 멘젠 여부·깡 개수는 직접 입력해주셔야 해요. 일발·천화·지화 등 사진만으로 알 수 없는 상황역도 직접 토글해주세요. 실제 판정은 함께하는 분들과 확인해주세요.

패 인식 모델은 Mahjong Tiles Model (Roboflow Universe, CC BY 4.0) 데이터셋으로 학습했어요.
